# 05. 운영 흐름 · 결과물 제작

## 1. 체험학습 4일 운영

| 시점 | 학생 | 교사 |
|---|---|---|
| 출발 전 사전 교육 | QR로 접속, PIN 로그인 연습, 미션 읽기 | PIN 카드 배부, 동의서 회수 → "사진 전시 동의" 입력 |
| 매일 낮 | 미션 장면 사진 촬영 (사진은 휴대폰에 그대로) | — |
| 매일 저녁 (숙소, 20:00 이후 30분) | 사진 1~3장 + 성찰 답변 + 소감문 + 한 줄 → 제출 | **제출 현황**에서 미제출 학생 확인·독려 |
| 다음 날 아침 | (필요하면 전날 기록 수정 제출) | 전날 DAY **마감** (선택) |
| 귀국 후 1주 | — | 검토·수정 → 승인, 카드 사진·대표 사진·전시 후보 선택 |
| 귀국 후 2주 | — | 결과물 생성 → 교정 → 출력 의뢰 |

숙소 와이파이가 붐비면 모둠별로 시간을 나눠 제출하게 하세요. 사진은 휴대폰에서 출력용 사본을 만들고 한 장씩 올리므로, 중간에 끊겨도 다시 누르면 이미 올라간 사진은 건너뜁니다.

## 2. 검토 · 편집 (관리자 → 검토 · 편집)

- **한 줄 기록 · 성찰 답변 · 소감문**: 맞춤법·문장을 다듬어 저장하면 *교사 수정본*으로 저장되고 학생 원문은 그대로 남습니다. "원문으로 되돌리기" 가능
- **승인 / 검토 대기 / 보류**: 결과물 제작 시 "승인된 기록만 사용"을 켜면 승인 기록만, 보류는 항상 제외
- **사진 도구**
  - `★ 카드` — 날짜별 포스터·기록 카드에 쓸 사진 (기본: 첫 번째 사진)
  - `메인` — 날짜별 A1 포스터 오른쪽 위 대표 사진 (날짜마다 1장)
  - `전시` — 팜플렛 "함께한 순간들"·주제 포스터에 우선 사용
  - `원본` — 휴대폰 원본 파일 보기
- **주제 분류**: 글의 키워드로 자동 분류(벗·발견·배려·성장). 버튼을 눌러 바꾸면 교사 지정으로 저장
- **학생 관리 → 선생님의 한마디**: 개인 성장 기록지 2쪽 하단에 실림 (비워 두면 손글씨용 줄)

## 3. 결과물 종류

| 결과물 | 크기 | 쪽수 | 구성 |
|---|---|---|---|
| 날짜별 포스터 ×4 | A1 세로 594×841mm | 1 | DAY 번호·주제·장소·미션·성찰 질문 + 대표 사진 + 학생 기록 카드 20장 (예시 Canva 카드와 같은 디자인) |
| 주제별 포스터 ×4 | A1 세로 | 1 | 벗·발견·배려·성장 도장 + 대표 기록(큰 사진·인용) + 기록 9편 |
| 개인 성장 기록지 | A4 | 학생당 2 (양면 1장) | 4일 한 줄 타임라인 · DAY별 사진/미션/성찰/소감문 · 선생님의 한마디 |
| 국제교류 팜플렛 | A5 또는 A4 | 16 (중철) | 표지 · B.U.T. 소개 · 일정 · DAY별 펼침면(여는 면+목소리 면) · 우리들의 한 줄 · 주제 · 사진 모음 · 마치며 · 뒤표지 |
| 기록 카드 | A5 | 제출 1건당 1 | Canva 대량 제작 예시와 같은 카드 + 소감 발췌 |
| 접속 안내 + PIN 카드 | A4 | 1 + 학생 10명당 1 | QR 안내문, 오려 쓰는 PIN 카드 |

모든 결과물은 같은 종이색(#F5F0E6), 남색 글자(#23303F), 주홍 도장 "벗", 날짜별 색(DAY1 주홍 · DAY2 남청 · DAY3 녹색 · DAY4 갈색), Gowun Dodum/Batang 글꼴을 공유해 디자인이 통일됩니다. 색·글꼴은 `src/shared/program.js` 의 `design` 에서 바꿉니다.

## 4. 파일 형식과 만드는 법

| 형식 | 용도 | 관리자 페이지 | PC 일괄 생성 |
|---|---|---|---|
| **PDF** | 출력소 납품·인쇄 | `PDF 인쇄` → 인쇄 창에서 PDF로 저장 | `generate-outputs.js` → `output/*.pdf` |
| **PPTX** | 편집 가능한 원본 (PowerPoint · Keynote · Google Slides · **Canva**에서 열기) | `PPTX` 내려받기 / `Drive 저장` | `output/*.pptx` |
| **HTML** | 웹 편집용 원본 (글을 직접 고쳐 다시 인쇄) | `HTML` | `output/*.html` + `photos/` |
| **CSV** | Canva **대량 제작(Bulk Create)** 데이터 | `Canva 대량 제작용 CSV` | — |
| **JSON** | 데이터 백업 | `데이터 백업(JSON)` | — |

### 고해상도 PDF 일괄 생성 (권장: A1 포스터)

관리자 페이지의 브라우저 인쇄도 가능하지만, A1은 PC에서 한 번에 만드는 편이 안정적입니다.

```bash
npm install
npm i -D playwright && npx playwright install chromium     # 처음 한 번
node scripts/generate-outputs.js --url "https://script.google.com/macros/s/배포ID/exec" --admin-password "비밀번호" --approved
# 일부만: --only day1,day2,topic-friend,growth,pamphlet-a5
```

`output/` 에 결과물마다 PDF · PPTX · HTML · 첫 쪽 미리보기 PNG가 생깁니다. 사진은 출력용 사본(긴 변 2000px)을 사용하므로 A1 포스터의 대표 사진(약 21×27cm)도 약 190dpi로 출력됩니다. 더 큰 사진이 필요하면 Drive `photos/original` 의 원본으로 PPTX에서 교체하세요.

### Canva에서 편집하기

- **PPTX 가져오기**: Canva → 만들기 → 가져오기 → PPTX 선택 → 글·사진·도형이 개별 요소로 열립니다 (사진의 둥근 모서리는 PPTX 특성상 직사각형으로 표시)
- **대량 제작**: Canva 디자인(예: 예시 카드)에 CSV를 연결 → `one_line`, `student_label`, `day_label`, `date` 필드를 텍스트에 연결, 사진은 Drive `photos/display` 의 파일명(`photo1_file`)을 기준으로 업로드해 연결

## 5. 출력 사양 (출력소 전달용)

| 결과물 | 용지·방식 | 비고 |
|---|---|---|
| A1 포스터 | 594×841mm, 실사/포스터 출력(무광 권장), 재단 여백 없음 | PDF 1쪽 = 포스터 1장 |
| 개인 성장 기록지 | A4 양면, 120g 이상 | 학생당 2쪽 → 양면 1장 |
| 팜플렛 A5 | A5 16쪽 중철, 표지 200g/내지 120g | 쪽 순서대로 PDF 제공(출력소에서 대지 배열) |
| 팜플렛 A4 | A4 16쪽 중철 | 같은 디자인을 A4로 확대 |
| 기록 카드 | A5 단면 또는 엽서 용지 | 제출 1건당 1장 |

출력 전 반드시 A4 축소 인쇄로 교정(오탈자·학생 이름·사진 동의)을 하세요.
