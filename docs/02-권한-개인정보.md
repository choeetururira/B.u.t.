# 02. 접근 권한 · 개인정보 보호

## 1. 누가 무엇에 접근하나

| 대상 | 접근 범위 | 방법 |
|---|---|---|
| 교사(소유자) | 시트·Drive 폴더·코드 전체 | Google 계정 |
| 공동 인솔 교사 | 관리자 페이지(현황·검토·결과물) | 관리자 비밀번호 (8시간 후 자동 로그아웃) |
| 학생 | **자기 기록만** 제출·조회·수정 (다른 학생 사진·글 접근 불가) | 학생 번호 + PIN |
| 웹앱 주소를 아는 외부인 | 로그인 화면만 | — |

- 웹앱은 **"나(교사)로 실행"** 됩니다. 학생은 Google 로그인이 필요 없고, 시트·폴더 공유도 필요 없습니다.
- 스프레드시트와 Drive 폴더는 **절대 링크 공유를 켜지 마세요.** 사진은 공개 링크 없이, 서버가 권한을 확인한 뒤 관리자·본인에게만 전달합니다.
- 결과물 데이터(`adminDataset`)에는 **실명이 포함되지 않습니다.** 포스터·기록지·팜플렛은 "표시 이름"(기본값 `STUDENT 07`)만 사용합니다.
- **전시 비동의** 학생(학생 관리 → 사진 전시 동의 해제)의 사진은 결과물에서 자동으로 빠지고 글만 실립니다.
- 검토 상태를 **보류**로 두면 그 기록은 결과물에서 제외됩니다.

## 2. 보안 장치 (코드에 구현됨)

| 위험 | 대응 | 위치 |
|---|---|---|
| PIN 무차별 대입 | 학생 번호별 5회 실패 → 60분 잠금, 관리자도 동일 | `core.js` `rateCheck` |
| 토큰 위조·변조 | HMAC-SHA256 서명 토큰, 학생 7일·관리자 8시간 만료 | `makeToken`/`readToken` |
| 다른 학생 사진 끼워 넣기 | 제출 시 사진의 소유자·날짜 확인 | `submit` |
| 관리 함수 원격 호출 | `setup`·`resetAdminPassword` 등은 스크립트 소유자만 실행 | `requireOwner_` |
| 관리자 비밀번호 유출 | 시트·코드에 평문 저장하지 않음(솔트+SHA-256 해시를 스크립트 속성에 저장) | `setAdminPassword` |
| 교사 편집으로 원문 손실 | 학생 원문과 교사 수정본을 별도 열에 저장, 재제출 이력 보관 | `edited*` 열, `status=superseded` |
| 오류 메시지로 내부 정보 노출 | 서버 오류는 일반 메시지로만 반환, 상세는 `Log` 시트 | `api()` |

공용 기기에서 학생이 쓴 뒤에는 **로그아웃**을 안내하세요(토큰이 기기에 7일 저장됨). 분실 기기가 생기면 해당 학생 PIN을 **재발급**하거나 `rotateTokenSecret` 으로 전원 로그아웃합니다.

## 3. 권한 범위(OAuth) 설명

`appsscript.json` 의 권한과 이유입니다. 승인 화면에서 교사에게 한 번 표시됩니다.

| 권한 | 이유 |
|---|---|
| `spreadsheets` | 제출 기록을 시트에 저장 |
| `drive` | 사진 원본·출력용 사본·결과물을 비공개 폴더에 저장, 테스트 데이터 삭제 시 휴지통 이동 |
| `userinfo.email` | 관리 함수 실행자가 소유자인지 확인 |

## 4. 동의서에 넣을 항목 (예시)

학교 양식에 맞춰 **개인정보 수집·이용 동의** 및 **초상권(사진) 활용 동의**를 받으세요.

| 항목 | 예시 |
|---|---|
| 수집 항목 | 학생 번호, (선택) 성명, 활동 사진, 성찰 답변·소감문·한 줄 기록 |
| 목적 | 국외현장체험학습 활동 기록, 결과물(포스터·기록지·팜플렛) 제작 및 교내 전시 |
| 보유 기간 | 결과물 제작·전시 종료 후 파기 (예: 2027. 2. 28.) |
| 제3자 제공 | 없음 (Google Workspace에 저장, 결과물은 교내 전시·배부) |
| 사진 활용 | 결과물에 사진 사용 동의 여부 (비동의 시 글만 게재) — 관리자 페이지 "사진 전시 동의"에 반영 |
| 자매학교 학생 | 일본 학생 얼굴이 크게 나온 사진은 상대 학교 동의 범위 안에서만 전시 |

## 5. 보존과 파기

1. 결과물 제작이 끝나면 관리자 페이지 **[데이터 백업(JSON)]** 과 Drive `outputs` 폴더의 결과물을 학교 보존 규정에 맞게 보관
2. 보유 기간이 지나면 관리자 페이지 **설정 → 가상(테스트) 데이터 삭제**(학생 명단 포함 체크) 실행 → 사진은 Drive 휴지통으로 이동
3. Drive **휴지통 비우기**, 스프레드시트 파일 삭제, Apps Script 배포 **보관 처리(사용 중지)**

## 6. 실명을 쓰지 않는 운영

학생 번호만 쓰고 실명 열은 비워 두어도 모든 기능이 동작합니다. 교사는 별도 명렬표로 번호와 이름을 대조하세요.
