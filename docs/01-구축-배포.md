# 01. 구축 · 배포 (Google Apps Script)

웹앱은 **교사 한 명의 Google 계정** 안에서 동작합니다. 학생 데이터(시트)와 사진(Drive)이 모두 그 계정에 비공개로 저장되므로 외부 서버나 유료 서비스가 필요 없습니다.

> 학교 Google Workspace 계정을 권장합니다. 단, 도메인 관리자가 "외부 사용자에게 웹앱 공개"를 막아 둔 학교가 있습니다. 4단계에서 **모든 사용자** 옵션이 보이지 않으면 정보부/도메인 관리자에게 허용을 요청하거나, 체험학습 전용 개인 Google 계정을 사용하세요.

## 준비물

- 교사 Google 계정 (Drive 여유 공간 2GB 이상 권장: 사진 원본 20명 × 4일 × 3장 × 약 4MB ≈ 1GB)
- PC: Node.js 18 이상 (빌드용). 결과물 고해상도 PDF 일괄 생성까지 하려면 Playwright도 설치합니다.

```bash
git clone <이 저장소> && cd B.u.t.
npm install
```

## 1단계 — 학교 정보 바꾸기

`src/shared/program.js` 에서 아래만 확인·수정하면 학생 화면, 관리자 화면, 모든 결과물에 반영됩니다.

| 항목 | 위치 | 예 |
|---|---|---|
| 학교명 | `schoolName` | `'○○고등학교'` → 실제 학교명 |
| 참가 인원 | `participants` | `20` |
| 일정·미션·성찰 질문 | `days[...]` | 첨부 일정표 기준으로 이미 입력됨 |
| 제출 규칙 | `rules` | 사진 1~3장, 소감문 100~3000자, 한 줄 30자 등 |
| 주제 분류 키워드 | `topics[...].keywords` | 벗·발견·배려·성장 |
| 색·글꼴 | `design` | 날짜별 색은 `days[].color` |

> **Node.js 없이 하려면**: 저장소의 `dist/gas/` 폴더에 빌드된 파일 4개가 이미 들어 있습니다. 학교명만 바꾸려면 세 파일(`Code.js`, `Student.html`, `Admin.html`)에서 `○○고등학교`를 모두 찾아 바꾼 뒤 3단계로 가세요.

## 2단계 — 빌드

```bash
npm run build
```

`dist/gas/` 에 4개 파일이 만들어집니다.

| 파일 | 내용 |
|---|---|
| `Code.js` | 서버 코드(설정 + 핵심 로직 + Sheets/Drive 저장 + 진입점) |
| `Student.html` | 학생 모바일 페이지 |
| `Admin.html` | 관리자 페이지 (레이아웃 엔진·PPTX 생성 포함) |
| `appsscript.json` | 권한 범위, 시간대, 웹앱 설정 |

## 3단계 — Apps Script 프로젝트에 올리기

### 방법 A. 붙여넣기 (가장 쉬움)

1. https://script.google.com → **새 프로젝트** → 이름: `B.U.T. TOKYO 2026`
2. 왼쪽 **파일**의 `Code.gs` 내용을 모두 지우고 `dist/gas/Code.js` 내용을 붙여 넣기
3. 파일 옆 **＋ → HTML** 로 `Student` 만들기 → `dist/gas/Student.html` 붙여 넣기 (이름에 `.html` 은 쓰지 않음)
4. 같은 방법으로 `Admin` 만들기 → `dist/gas/Admin.html` 붙여 넣기
5. **프로젝트 설정(⚙)** → "편집기에서 'appsscript.json' 매니페스트 파일 표시" 체크 → `appsscript.json` 을 `dist/gas/appsscript.json` 내용으로 교체
6. 저장 (Ctrl+S)

### 방법 B. clasp (코드 수정이 잦을 때)

```bash
npm i -g @google/clasp
clasp login                                  # 브라우저에서 교사 계정으로 로그인
# https://script.google.com/home/usersettings 에서 "Google Apps Script API" 사용 설정
clasp create --type standalone --title "B.U.T. TOKYO 2026" --rootDir dist/gas
npm run push:gas                             # 빌드 + 업로드
```

`.clasp.json` 은 계정 정보가 담기므로 저장소에 올리지 않습니다(`.gitignore` 처리됨). 예시는 `.clasp.json.example`.

## 4단계 — 초기 설정 `setup()`

1. 편집기 위쪽 함수 선택에서 **`setup`** → **실행**
2. 처음 실행하면 권한 요청이 나옵니다 → **권한 검토** → 교사 계정 선택 → (경고가 나오면) **고급 → B.U.T. TOKYO 2026(으)로 이동** → **허용**
   - 요청 권한: 스프레드시트, Drive, 이메일 주소(소유자 확인용). 이유는 [02-권한-개인정보.md](02-권한-개인정보.md) 참고
3. **실행 로그**에 다음이 표시됩니다.
   ```
   Drive 폴더 생성: https://drive.google.com/drive/folders/...
   스프레드시트 생성: https://docs.google.com/spreadsheets/d/...
   관리자 비밀번호(지금 한 번만 표시): xxxxxxxxxxxx   ← 안전한 곳에 기록
   학생 20명 생성 (Students 시트에서 PIN 확인)
   ```
4. 비밀번호를 잊었으면 `resetAdminPassword` 를 실행해 새로 발급합니다.

`setup()` 은 여러 번 실행해도 이미 만든 시트·폴더·비밀번호를 건드리지 않습니다.

## 5단계 — 웹앱 배포

1. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙) → **웹 앱**
2. 설명: `v1` · **다음 사용자 인증 정보로 실행: 나** · **액세스 권한이 있는 사용자: 모든 사용자**
3. **배포** → 웹 앱 URL 복사
   - 학생: `https://script.google.com/macros/s/배포ID/exec`
   - 관리자: 같은 주소 끝에 `?page=admin`

"모든 사용자"여도 누구나 보는 것은 **로그인 화면뿐**입니다. 모든 데이터 요청은 학생 PIN 또는 관리자 비밀번호로 발급된 서명 토큰이 있어야 합니다.

## 6단계 — 주소 · QR 배부

관리자 페이지 → **학생 관리**에서 표시 이름·실명(선택)·전시 동의를 입력 → **결과물 제작 → 접속 안내(QR) + PIN 배부 카드 A4 → PDF 인쇄**. 1쪽은 교실 게시용 QR 안내문, 2쪽부터 학생별로 오려 나눠 줄 PIN 카드입니다.

## 코드를 고친 뒤 다시 배포하기 (주소 유지)

1. `npm run build` → 바뀐 파일을 다시 붙여넣기 (또는 `npm run push:gas`)
2. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**

> **새 배포**를 누르면 주소가 바뀝니다. 학생에게 QR을 나눠 준 뒤에는 반드시 **배포 관리 → 새 버전**으로 갱신하세요.

## 운영 중 확인할 곳

| 무엇 | 어디서 |
|---|---|
| 시트·폴더 주소 | 편집기에서 `showSetupInfo` 실행 |
| 오류 기록 | 스프레드시트 `Log` 탭, Apps Script **실행** 메뉴 |
| 모든 로그인 강제 해제 | `rotateTokenSecret` 실행 (분실 기기 등) |
