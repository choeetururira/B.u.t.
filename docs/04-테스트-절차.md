# 04. 테스트 절차 (가상 데이터 → 실제 사용)

**원칙: 실제 학생 정보를 넣기 전에 가상 학생 20명 데이터로 제출과 결과물 생성을 끝까지 확인합니다.**
가상 데이터는 `scripts/virtual-data.js`(글)와 `scripts/make-virtual-photos.py`(합성 사진)가 만들며 실제 인물·개인정보가 없습니다.

## 1단계 — 자동 테스트 (PC, 약 1분)

```bash
npm install
npm run photos     # 처음 한 번
npm test
```

## 2단계 — 로컬 리허설 (PC 브라우저 + 휴대폰)

```bash
npm start          # 학생 http://localhost:8080 · 관리자 /admin (비밀번호 test-admin-2026)
npm run seed       # 가상 77건 제출
npm run outputs    # output/ 에 결과물 생성
```

같은 와이파이의 휴대폰으로 `http://PC의IP:8080` 에 접속하면 실제 휴대폰 화면도 확인할 수 있습니다.
(로컬 데이터는 `data/local/` 에 저장되며, 지우려면 서버를 끄고 폴더를 삭제합니다.)

## 3단계 — Apps Script 배포본 리허설 (출발 2주 전)

[01-구축-배포.md](01-구축-배포.md) 로 배포한 뒤, **배포 주소**에 같은 가상 데이터를 넣습니다.

### 실제 기기 점검표

교사·인솔 교사 휴대폰 2~3대(아이폰 Safari, 안드로이드 Chrome)로 직접 확인합니다.

|---|---|---|
| 1 | QR 안내문 인쇄본을 **카메라 앱**과 **카카오톡 QR**으로 스캔 | 학생 로그인 화면이 열림 (카카오톡 인앱 브라우저 포함) |

| 4 | 아이폰 HEIC 사진 | 정상 업로드(사파리가 JPG로 변환). 실패 시 안내 문구 표시 |
| 5 | 글 작성 중 앱 전환 → 복귀, 새로고침 | 임시저장 내용 유지 |

| 8 | 비행기 모드로 제출 | "인터넷 연결이 불안정합니다" 안내, 글 유지 → 연결 후 재제출 성공 |
| 9 | 관리자: 제출 현황 | 77/80, 미제출 칸 표시 |

## 4단계 — 실제 사용으로 전환 (출발 1주 전)

1. 관리자 **설정 → 가상(테스트) 데이터 삭제** → `DELETE` 입력 → 모두 삭제
   (가상 PIN이 노출됐다면 "학생 명단과 PIN도 삭제"를 체크하고 **학생 관리 → 학생 번호 생성**으로 새 PIN 발급)
2. Drive **휴지통 비우기** (가상 사진 완전 삭제)
3. **학생 관리**: 표시 이름(예: `STUDENT 07` 또는 별칭), 실명(선택), **사진 전시 동의** 여부 입력 → 저장
4. **설정**: 제출 가능 날짜를 `해당 날짜부터`로 바꿀지 결정 (사전 안내 기간에는 `모든 DAY`)
5. **결과물 → 접속 안내(QR) + PIN 배부 카드** 인쇄 → 사전 교육 때 배부, 각자 1회 로그인 연습
6. 사전 교육에서 DAY 01을 연습 제출한 경우: 관리자가 해당 기록을 **보류**로 두거나, 학생이 첫날 저녁에 다시 제출(2회차로 교체)

## 문제 해결

| 증상 | 원인·조치 |
|---|---|
| "등록되지 않은 학생 번호" | 학생 관리에서 `사용` 체크 확인, 번호 앞 0(`07`) 확인 |
| 사진 업로드가 오래 걸림 | 숙소 와이파이 혼잡 → 몇 명씩 나눠 제출. 원본 20MB 초과 사진은 업로드 불가 |
| 관리자 PDF 인쇄 시 용지가 A4로 나옴 | 인쇄 창 **용지 크기**를 결과물 크기로, **여백 없음**, **배경 그래픽** 선택. 고해상도는 `generate-outputs.js` 사용 |
| PPTX 글꼴이 다르게 보임 | PC에 [Gowun Dodum](https://fonts.google.com/specimen/Gowun+Dodum) · [Gowun Batang](https://fonts.google.com/specimen/Gowun+Batang) 설치 |
| 관리자 PPTX/HTML 내려받기가 반응 없음 | 브라우저가 Apps Script 화면 안의 다운로드를 막는 경우 → **Drive 저장** 버튼 사용 또는 PC 일괄 생성 |
| 학생 화면이 예전 그대로 | 배포 관리에서 **새 버전**으로 갱신했는지 확인 |
